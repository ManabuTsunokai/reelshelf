Convert and upload a video

If your video cannot be played in a browser, convert it with the free video converter HandBrake before uploading it.

1. Install HandBrake

Download the version for your Mac or Windows computer from the official HandBrake download page, then follow the installation instructions.

Always download HandBrake from its official website.

2. Open the video to convert

Open HandBrake, then select the video file that you want to convert.

3. Choose the preset and optimize for the web

Select Fast 1080p30 from the Preset menu at the top of the window. Then, on the Summary tab, select Web Optimized.

For now, you do not need to change any other settings.

4. Start the conversion

Confirm the destination and file name, then select Start Encode. Keep HandBrake open until the conversion finishes. A new video file will be created in the chosen destination.

5. Upload to Tamareel

Sign in to Tamareel and select the new video file created by HandBrake from the upload screen. Keep the original video file yourself if you need it.
