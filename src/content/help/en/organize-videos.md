## The four main areas

- **Videos:** View all videos that have not been archived. Videos remain here after you add them to a series.
- **Series:** Group videos that belong together or cover the same topic. A video can belong to only one series.
- **Playlists:** Arrange videos for a particular purpose or viewing order. The same video can be added to several playlists.
- **Archive:** Keep videos without showing them in the regular Videos list.

Adding a video to a series or playlist does not duplicate the video file or increase the storage it uses.

## Find videos and filter by tag

The search box at the top of the screen searches within the current Videos, Series, Playlists, or Archive view.

1. Enter part of a title or description in the search box.
2. To search for the text you entered, press Enter or select the search button.
3. To filter by tag, select a tag from the suggestions that appear while you type. Selected tags appear inside the search box.
4. To remove a filter, clear the search text or select the remove button on a selected tag.

When you select several tags, only items matching all of them are shown. A series search includes the series, its sections, and their videos. A playlist search includes the playlist and its videos.

Use Sort at the bottom of a list to sort by title, creation date, update date, rating, capture date, and other available fields, and to switch between ascending and descending order. Inside a series or playlist, you can also display videos in their saved series or playlist order.

## Edit video information

Adding information to a video makes it easier to recognize later and more useful in search and sorting.

### Edit one video

1. Open Videos, open the video's action menu, and select Edit details. You can also open the video first and select Edit details from Video actions.
2. Update the fields you need on the Basic information and Tags tabs.
3. Select Save.

The Basic information tab contains these fields:

- **Title:** The name shown in lists and on the playback screen. A title is required.
- **Description:** Notes or a summary of the video's contents. Titles and descriptions are included in text searches.
- **Capture date:** Enter a year, year and month, full date, or date and time. For example, enter `2026`, `2026-08-25`, or `2026-08-25 14:30`. This field is also used when sorting by capture date.
- **Location:** Enter the place name you want to associate with the video. If latitude and longitude were obtained from the video, they appear below this field for reference.
- **Rating:** Give the video a rating. Ratings can be used for sorting. Clear the rating to return it to an unset state.

On the Tags tab, search for and select existing tags. If the tag you need does not exist, create one using the name you entered. To remove a tag, remove it from the selected tags before saving.

### Edit several videos at once

1. Select Select in the upper-right corner of the Videos page.
2. Select the videos you want to edit. You can also drag a selection box around several cards.

3. Open Bulk actions and select Edit details.
4. Turn on the edit toggle beside every field you want to change, then enter the value to apply to all selected videos.
5. Select Save.

Only fields whose edit toggles are on will be updated. Title, description, capture date, location, and rating are set to the same value for every selected video. Save an empty description, capture date, or location to clear that field on every selected video. Clear the rating before saving to return it to an unset state. Title is required and cannot be empty.

Tags have two update modes:

- **Add:** Add the selected tags to each video's current tags. Existing tags remain in place.
- **Replace:** Remove each video's current tags and replace them with the selected tags. Replacing with no tags selected removes all tags from the selected videos.

### Change the thumbnail

Thumbnails are managed separately from Edit details. Open a video and select Set thumbnail from Video actions. You can choose an image file or use the current frame from the player. Check the preview, then select Save. To remove a custom thumbnail, select Clear.

## Group related videos into a series

Series work well for courses, events, episodes, or other videos that belong together. A video can belong to one series only, and it is placed in one section within that series.

### Create a series

1. Open Series from the main menu.
2. Select Add series.
3. Enter a title, description, and tags.
4. If you want to divide the series into several groups, turn on Section hierarchy, then select Add.

The first section is created automatically with a new series. To add sections such as Basics, Part 1, and Part 2, open the series and select the add button beside the section names, or choose Add section from a section's action menu. A section can have its own position, title, description, and tags.

### Add videos to a series

To add a video from the Videos page:

1. Open the action menu for a video that does not belong to a series and select Add to series.
2. Select the destination series.
3. If the series has several sections, select the destination section.
4. Confirm the destination and select Add 1. When several videos are selected, the button shows the number of videos that will be added.

To add several videos, select Select on the Videos page, select the videos, then choose Add to series from Bulk actions. You cannot add a mixed selection containing both videos that already belong to a series and videos that do not.

You can also open a series and choose Add videos from Series actions to add unassigned videos.

### Organize videos within a series

- Select a section name at the top of a series to switch sections.
- In list view, drag a video's handle to change its position within the section. Reordering is unavailable while searching.
- Choose Move to another section from a video's action menu to move it within the same series.
- Choose Remove from series to leave the video itself in Videos as an unassigned video. To move a video to a different series, remove it from its current series first, then add it to the new one.
- In grid view, use Select and Bulk actions to edit details, add videos to a playlist, move them to another section, or remove them from the series together.

When deleting a series or section that contains videos, choose whether to keep its videos in Videos or delete the videos as well. Deleting the videos cannot be undone, so check the selected option carefully on the confirmation screen.

## Make purpose-based lists with playlists

Use playlists for collections such as Watch later, Favorites, or Family vacation. Playlist membership is separate from series membership, and the same video can be used in several playlists.

### Create a playlist

1. Open Playlists from the main menu.
2. Select Add playlist.
3. Enter a title, description, and tags, then select Add.

Use a playlist's action menu to edit its information or delete it. Deleting a playlist does not delete the videos it contains.

### Add and arrange videos

1. Open a video's action menu on the Videos page and select Add to playlist.
2. Select the destination playlist.
3. Confirm the destination and select Add 1. When several videos are selected, the button shows the number of videos that will be added. Videos are added to the end of the playlist.

To add several videos, use Select, choose the videos, then select Add to playlist from Bulk actions. You can also open a playlist and select Add videos from Playlist actions.

In a playlist's list view, drag a video's handle to change the playback order. Choosing Remove from playlist from the video's action menu removes only its playlist membership; the video remains in Videos.

## Keep Videos tidy with the archive

Move videos that you do not need to see for a while to the archive instead of deleting them.

1. Open a video's action menu on the Videos page and select Archive.
2. To archive several videos, select them with Select, then choose Archive from Bulk actions.
3. To restore a video, open Archive from the main menu and select Restore from the video's action menu. You can also select and restore several videos together.

Archiving does not delete a video or change its storage usage. Its series and playlist memberships are preserved. An archived video no longer appears in the regular Videos list, but it remains available from its series and playlists.

## Understand the difference between archiving and deleting

Deleting permanently removes a video from the library. The video also disappears from its series and playlists and cannot be restored. If you might need the video again, archive it first instead.

A source video cannot be deleted while an edited video references it. Archive the source if you only want to hide it from the regular list. See “[About video editing](/en/help/editing-videos/)” for instructions and more information about the relationship between source and edited videos.
